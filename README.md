# 📊 Employee Attendance Dashboard | Power BI

**Project Overview**  
This repository contains an **interactive Employee Attendance Dashboard** built using **Microsoft Power BI**. The dashboard helps HR teams and business leaders monitor, analyze, and visualize employee attendance patterns efficiently. It provides actionable insights into attendance behavior, leaves, and workforce trends to support data-driven decision-making. :contentReference[oaicite:0]{index=0}

---

## 📌 Why This Project?

Employee attendance is a crucial metric for workforce productivity and organizational efficiency. Manual attendance tracking often lacks visibility and interactivity — this Power BI dashboard transforms raw attendance data into dynamic visuals that make it easier to understand trends, identify issues, and optimize HR strategies. :contentReference[oaicite:1]{index=1}

---

## 🧰 Tools & Technologies Used

| Tool | Purpose |
|------|---------|
| **Power BI Desktop** | Main tool for dashboard building and visualization |
| **Power Query** | Data cleaning, transformation, and modeling |
| **DAX (Data Analysis Expressions)** | Calculations for dynamic KPIs and measures |
| **Excel / SQL Server** | Data sourcing and pre-processing |

---

## 📊 Key Features

### ✅ Attendance KPIs  
- Total Working Days  
- Total Present Days  
- Total Leaves & Absences  
- Attendance Percentage (auto-calculated with DAX)

---

### 📍 Analytics & Insights

📌 **Overview & Trends**
- Department-wise and employee-wise attendance distribution
- Monthly attendance trends and patterns
- Breakdown of present vs absent vs on leave  
📌 **Interactive Filters**
- Slicers for Year / Month / Department / Employee  
📌 **Dynamic Visuals**
- KPI cards
- Bar and column charts
- Line charts and trend visuals
- Department comparisons

Each visual updates automatically when filters are applied, allowing deep insight into attendance behavior across teams and time. :contentReference[oaicite:2]{index=2}

## 📂 Dataset

The dataset used for this dashboard includes:
- Employee IDs & Names
- Dates of attendance records
- Attendance status (Present, Absent, Leave)
- Department information

> 💡 You can replace this with your own HR or attendance dataset — ensure it has consistent date formats and status labels for best performance.
