# 📊 Employee Attendance Dashboard | Power BI

**Project Overview**  
This repository contains an **interactive Employee Attendance Dashboard** built using **Microsoft Power BI**. The dashboard helps HR teams and business leaders monitor, analyze, and visualize employee attendance patterns efficiently. It provides actionable insights into attendance behavior, leaves, and workforce trends to support data-driven decision-making.

## 📌 Why This Project?

Employee attendance is a crucial metric for workforce productivity and organizational efficiency. Manual attendance tracking often lacks visibility and interactivity — this Power BI dashboard transforms raw attendance data into dynamic visuals that make it easier to understand trends, identify issues, and optimize HR strategies.

---

## 🧰 Tools & Technologies Used

| Tool | Purpose |
|------|---------|
| **Power BI Desktop** | Main tool for dashboard building and visualization |
| **Power Query** | Data cleaning, transformation, and modeling |
| **DAX (Data Analysis Expressions)** | Calculations for dynamic KPIs and measures |
| **Excel / SQL Server** | Data sourcing and pre-processing |

---

## 📊 Key Features

### ✅ Attendance KPIs  
- Total Working Days  
- Total Present Days  
- Total Leaves & Absences  
- Attendance Percentage (auto-calculated using DAX)

---

### 📍 Analytics & Insights

📌 **Overview & Trends**
- Department-wise and employee-wise attendance distribution  
- Monthly attendance trends and patterns  
- Breakdown of Present vs Absent vs On Leave  

📌 **Interactive Filters**
- Slicers for Year, Month, Department, and Employee  

📌 **Dynamic Visuals**
- KPI cards  
- Bar and column charts  
- Line charts for trend analysis  
- Department-wise comparisons  

Each visual updates automatically when filters are applied, enabling deeper insights into attendance behavior across teams and time.

## 📂 Dataset

The dataset used for this dashboard includes:
- Employee IDs & Names  
- Attendance dates  
- Attendance status (Present, Absent, Leave)  
- Department information  

> 💡 You can replace this dataset with your own HR or attendance data. Ensure consistent date formats and standardized attendance labels for accurate results.
